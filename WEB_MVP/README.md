# Kabadiwala Connect — SIH26229 MVP v0.1

## What this is
A presentation-ready functional prototype of the collector journey:

Home → Add Scrap → AI Identification → Price Discovery → Recycler Matching → Digital Lot → Handover → Earnings.

## Run
No build tools are required.

1. Extract the folder.
2. Open it in VS Code.
3. Double-click `index.html` or use the VS Code Live Server extension.
4. Open the page in Chrome on desktop or mobile.

## Important
This is an MVP prototype. AI identification, recycler data, price data, payments and QR verification are simulated locally so the full product journey can be demonstrated quickly.
